2. QUY TRÌNH KHI SỬA GIAO DIỆN

Bước 1. Sửa trong thư mục frontend\, không sửa trực tiếp trong moi\.
Bước 2. Xem thử trên máy:
          docker compose up -d --build
        Mở http://localhost:3000 (nếu file .env có đặt WEB_PORT thì dùng cổng đó).
        Khi đang chạy, sửa code trong frontend\ sẽ tự cập nhật; bấm Ctrl+F5.
Bước 3. Kiểm tra lỗi (cần chạy "npm install" trong frontend\ một lần trước):
          cd frontend
          npm run typecheck
Bước 4. Nếu file vừa sửa có trong danh sách ở mục 5, chép đè nó sang moi\ theo
        đúng đường dẫn. Ví dụ, chạy tại thư mục gốc của dự án:
          copy /y frontend\src\components\site\site-nav.css sao-luu-giao-dien\moi\src\components\site\site-nav.css
        BỎ BƯỚC NÀY thì lần sau chạy dung-giao-dien-moi.bat sẽ ghi bản cũ trong
        moi\ đè lên, phần vừa sửa bị mất.
Bước 5. Commit.
Bước 6. Đưa lên server: lấy code mới về server, rồi chạy trên server:
          docker compose -f docker-compose.server.yml up -d --build
        KHÔNG thêm "down -v": lệnh đó xóa vĩnh viễn dữ liệu.


3. ĐỔI GIỮA GIAO DIỆN CŨ VÀ MỚI

Bước 1. Commit trước, để lấy lại được nếu cần. Nếu sắp đổi về giao diện cũ, kiểm
        tra moi\ đã khớp với frontend\ (bước 4 ở mục 2).
Bước 2. Trên máy Windows, nhấp đúp một trong hai file:
          khoi-phuc-giao-dien-cu.bat    quay lại giao diện cũ
          dung-giao-dien-moi.bat        đổi sang giao diện mới
Bước 3. Mở trang web trên máy, bấm Ctrl+F5 và chạy "npm run typecheck".
Bước 4. Muốn áp dụng cho server: commit rồi làm bước 6 ở mục 2.

LƯU Ý
- Hai file .bat GHI ĐÈ các file ở mục 5, không hỏi lại.
- Giao diện cũ không có các chỉnh sửa làm sau ngày sao lưu 26/11/2026 trong những
  file đó (ví dụ cỡ logo và menu mới).
- Khi đã về giao diện cũ, ba file theme-gradient.css, useCardTables.ts và
  siteHeader.ts vẫn nằm trong frontend\ nhưng không được dùng. Không cần xóa.
- Nếu sau này sửa các file KHÔNG có trong danh sách, giao diện cũ có thể không còn
  chạy khớp: vì vậy phải chạy "npm run typecheck" sau khi khôi phục.
- Dữ liệu (bài viết, số đặc san, tài khoản...) không bị ảnh hưởng.


4. ĐỔI LOGO

Cách thường dùng, không cần sửa code hay build lại:
  Trang quản trị > Giao diện > Logo > tải ảnh lên rồi lưu.
  Bấm "Dùng logo mặc định" để quay về logo.png.
Logo tải lên trong trang quản trị được ưu tiên hơn logo.png ở cả hai giao diện.

Muốn đổi logo mặc định: thay cả hai file frontend\public\logo.png và
sao-luu-giao-dien\moi\public\logo.png.
